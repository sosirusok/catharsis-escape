# 카타르시스 이스케이프

부산 서면 카타르시스 이스케이프의 고객 예약 사이트와 예약·운영 관리자 프로젝트입니다.

## 운영 링크

- 고객 사이트: https://sosirusok.github.io/catharsis-escape/
- 예약·운영 관리자: https://sosirusok.github.io/catharsis-2vdf9n5pq1/
- 네이버 지도: https://map.naver.com/p/entry/place/1626605361

관리자 링크에서는 별도 계정 로그인 없이 관리자 키를 확인합니다. 키와 세션 서명값은 서버 환경에만 보관하며 저장소와 브라우저 코드에는 포함하지 않습니다.

## 고객 기능

- 관리자 설정을 반영하는 테마 소개·요금·난이도·인원 안내
- Asia/Seoul 기준 자동 순환 예약 날짜
- 예약 가능 시간 확인과 중복 예약 차단
- 대표자 이름·전화번호·인원 입력, 선택된 결제기관 승인 후 예약 코드 발급
- 결제 중 슬롯 잠금, 결제 완료 전 예약 확정 차단, 중복 결제·중복 예약 방지
- 예약 조회·원결제수단 환불과 취소된 시간의 자동 재오픈
- 매장 위치, 실제 지도, 방문 안내
- 데스크톱·태블릿·모바일 반응형 UI

## 운영 관리자 기능

- 날짜별 예약 조회, 직접 예약 추가, 상태·인원·연락처·메모 관리
- 테마 추가·수정·운영 종료, 이미지·설명·난이도·시간·인원·가격 관리
- 요일별 반복 시간표와 특정 날짜 시간 추가·마감
- 매장 전체 또는 테마별 휴무 관리
- 예약 공개 기간, 당일 마감, 고객 취소 마감, 접수 일시 중지 설정
- 결제 상태·결제수단·결제금액 확인과 관리자 환불 처리

## 사장님 예약 알림 앱

`owner-app`은 Android 전용 예약 알림 앱입니다. 최초 실행 시 관리자 키를 한 번 확인한 뒤 기기별 보안 토큰으로 연결하며, 결제 승인·예약 취소를 Firebase 푸시로 알리고 문자함 형태로 보관합니다. 푸시에는 개인정보를 싣지 않고 앱이 인증된 API에서 상세 내용을 다시 가져옵니다. 앱에는 관리자 키·결제 시크릿 키·Firebase 서비스 계정 키를 포함하지 않습니다.

## 데이터와 보안

- Cloudflare D1 기반 영구 예약 데이터
- 활성 예약의 슬롯 단위 고유 제약으로 동시 중복 예약 차단
- 예약자 이름·전화번호 AES-GCM 암호화
- 전화번호 조회용 HMAC, 요청 속도 제한, 관리자 변경 이력
- 서버 검증형 관리자 키, 실행 환경별 서명 세션, 최소 범위 CORS 정책
- 네이버페이 서버 승인·주문번호·금액·과세금액 검증, 멱등 처리와 180초 이후 거래 대사
- 거래별 결제사 기록과 기존 토스페이먼츠 거래의 조회·환불 호환
- 사장님 앱의 기기별 임의 토큰, 서버 저장 알림 이력, 로컬 보관
- 기기별 FCM 발송 대기열·임대 잠금·재시도와 푸시 누락 시 주기 동기화

## 네이버페이 운영 설정

가맹점 심사와 서비스 검수를 마친 뒤 신규 온라인 결제를 네이버페이 독립몰 결제형으로 전환합니다. 서버 실행 환경에 `NAVER_PAY_CLIENT_ID`, `NAVER_PAY_CLIENT_SECRET`, `NAVER_PAY_CHAIN_ID`, `NAVER_PAY_MODE=production`, `PAYMENT_PROVIDER=naverpay`를 모두 설정해야 활성화됩니다. 과세 구분은 세무 확인 후 `NAVER_PAY_TAX_SCOPE=taxable` 또는 `tax_exempt`로 명시합니다. 클라이언트 시크릿은 서버 환경에만 저장하며 GitHub Pages나 저장소에 넣지 않습니다.

승인 전에는 `PAYMENT_PROVIDER=toss`를 유지해 기존 카드결제를 중단하지 않습니다. 전환 뒤에도 토스페이먼츠 거래의 취소·대사를 위해 Toss 서버 어댑터와 서버 전용 키는 과거 거래의 환불 가능 기간 동안 유지합니다.

## 배포 구조

고객 화면과 관리자 화면은 각각 GitHub Pages에 배포됩니다. 예약 API, 관리자 키 검증, D1 데이터베이스와 R2 이미지 저장소는 별도 서버 런타임에서 실행되며 두 GitHub 사이트가 동일한 실시간 예약 데이터를 사용합니다.
